### ALGO-000203: Deterministic polynomial-time finite-field polynomial factorization
- **Subfield:** Computational number theory, lattices, and topology
- **Open:** Factor arbitrary univariate polynomials over finite fields deterministically in time polynomial in degree and \(\log q\), without unproved number-theoretic assumptions.
- **Status:** Randomized polynomial-time algorithms are classical. General unconditional deterministic polynomial time remains open.
